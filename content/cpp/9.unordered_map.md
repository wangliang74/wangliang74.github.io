# 数据结构

std::unordered_map 本质上是一张哈希表，按 key 查找、插入、删除的平均时间复杂度是 O(1)，不保证元素有序。

每个元素是 `std::pair<const Key, T>`。key 是 const，插入后不能改 key，只能改 mapped 值。

GCC/libstdc++ 里，哈希表由一组桶（bucket）组成，发生哈希冲突时，同一个桶里用链表串起多个节点：

```
template <class Key, class T,
          class Hash = hash<Key>,
          class Pred = equal_to<Key>,
          class Alloc = allocator<pair<const Key, T>>>
class unordered_map {
    // 逻辑上可以理解成：
    // buckets[i] -> node -> node -> ...
    //
    // hash(key) % bucket_count() 得到桶下标
    // 再在该桶的链表里用 key 相等比较找到节点
};
```

查找过程：
```
h = hash(key)
i = h % bucket_count()
在 buckets[i] 的链表里找 Pred(node->key, key) 为 true 的节点
```

常用接口与表状态的关系：
```
size()           // 当前元素个数
empty()          // size() == 0
bucket_count()   // 桶的数量
bucket(key)      // 该 key 落在哪个桶
bucket_size(i)   // 第 i 个桶里有多少个节点
load_factor()    // size() / bucket_count()，装载因子
max_load_factor()// 超过这个值就触发 rehash，默认通常是 1.0
```

执行 `insert` / `emplace` / `operator[]` 添加新元素时，先算哈希找到桶。如果该 key 已存在，不会再插入一份（map 的 key 唯一）。如果是新 key，在对应桶里挂上新节点，然后判断是否需要扩容（rehash）。

# 扩容处理

扩容时机：插入新元素后，如果 `size() > bucket_count() * max_load_factor()`，触发 rehash。

扩容处理：
+ 计算新的桶数量（通常扩到更大的质数，保证 `load_factor` 重新降下来）。
+ 申请新的桶数组。
+ 把旧表里的每个节点重新计算 `hash(key) % 新桶数`，挂到新桶上。
+ 释放旧的桶数组。
+ 节点对象本身一般不重新构造，只是改挂接关系；但迭代器、指针、引用会失效。

注意：vector 扩容会搬元素、可能调用拷贝/移动构造。unordered_map 的 rehash 主要是节点重新分桶，元素对象通常不用再构造一遍。

# 扩容如何影响迭代器

rehash 之后，原先的 iterator 全部失效，不能再解引用、不能再 erase。

示例代码：
```
#include <iostream>
#include <unordered_map>
#include <string>

int main() {
    std::unordered_map<int, std::string> m;
    m.max_load_factor(1.0f);
    m.reserve(1);

    m[1] = "a";
    auto it = m.find(1);
    std::cout << "before rehash, it->first: " << it->first << std::endl;

    m.rehash(100); // 强制扩容
    // 不要再使用 it
    std::cout << "after  rehash, find(1):   " << m.find(1)->second << std::endl;
    return 0;
}
```

运行结果：
```
before rehash, it->first: 1
after  rehash, find(1):   a
```

如果 `rehash` 之后继续用旧的 `it`，属于未定义行为。需要的 key 应重新 `find`。

# 容量接口

示例代码：
```
int main() {
    std::unordered_map<int, int> m;

    std::cout << "==========================================" << std::endl;
    std::cout << "size():            " << m.size() << std::endl;
    std::cout << "bucket_count():    " << m.bucket_count() << std::endl;
    std::cout << "load_factor():     " << m.load_factor() << std::endl;

    m.reserve(10); // 预留大约能装 10 个元素的桶，减少多次 rehash

    std::cout << "==========================================" << std::endl;
    std::cout << "size():            " << m.size() << std::endl;
    std::cout << "bucket_count():    " << m.bucket_count() << std::endl;
    std::cout << "load_factor():     " << m.load_factor() << std::endl;

    for (int i = 0; i < 3; ++i) {
        m.emplace(i, i * 10);
    }

    std::cout << "==========================================" << std::endl;
    std::cout << "size():            " << m.size() << std::endl;
    std::cout << "bucket_count():    " << m.bucket_count() << std::endl;
    std::cout << "load_factor():     " << m.load_factor() << std::endl;

    m.rehash(50); // 直接指定桶数量

    std::cout << "==========================================" << std::endl;
    std::cout << "size():            " << m.size() << std::endl;
    std::cout << "bucket_count():    " << m.bucket_count() << std::endl;
    std::cout << "load_factor():     " << m.load_factor() << std::endl;
    return 0;
}
```

运行结果（桶数量与实现有关，数量级大致如下）：
```
==========================================
size():            0
bucket_count():    1
load_factor():     0
==========================================
size():            0
bucket_count():    11
load_factor():     0
==========================================
size():            3
bucket_count():    11
load_factor():     0.272727
==========================================
size():            3
bucket_count():    53
load_factor():     0.0566038
```

`reserve(n)` 的含义是：按当前 `max_load_factor`，预留足够桶，使插入 n 个元素时尽量不 rehash。不是预留 n 个桶。

# 访问接口

示例代码：
```
int main() {
    std::unordered_map<std::string, int> m;
    m["apple"] = 1;
    m["banana"] = 2;

    std::cout << m["apple"] << std::endl;          // key 不存在会插入默认值 0
    std::cout << m.at("banana") << std::endl;      // key 不存在抛 out_of_range
    std::cout << m.count("apple") << std::endl;    // 存在返回 1，否则 0
    std::cout << (m.find("pear") == m.end()) << std::endl;

    auto it = m.find("apple");
    if (it != m.end()) {
        std::cout << it->first << ": " << it->second << std::endl;
    }
    return 0;
}
```

运行结果：
```
1
2
1
1
apple: 1
```

注意：`operator[]` 在 key 不存在时会插入 `{key, T()}`。只查询、不插入时，用 `find` 或 `at`。

```
int main() {
    std::unordered_map<std::string, int> m;
    std::cout << m.size() << std::endl; // 0
    int x = m["missing"];               // 插入 missing -> 0
    std::cout << m.size() << std::endl; // 1
    std::cout << x << std::endl;        // 0
    return 0;
}
```

# 遍历接口

unordered_map 不保证遍历顺序，顺序可能随实现、桶数量变化。

示例代码：
```
int main() {
    std::unordered_map<int, int> m;
    m.emplace(1, 10);
    m.emplace(2, 20);
    m.emplace(3, 30);

    std::cout << "==========================================" << std::endl;
    std::cout << "size():         " << m.size() << std::endl;
    std::cout << "bucket_count(): " << m.bucket_count() << std::endl;

    // 方式一：迭代器遍历
    for (auto it = m.begin(); it != m.end(); ++it) {
        std::cout << it->first << ": " << it->second << ", ";
    }
    std::cout << std::endl;

    // 方式二：Range-based for
    for (const auto& kv : m) {
        std::cout << kv.first << ": " << kv.second << ", ";
    }
    std::cout << std::endl;

    // 方式三：结构化绑定
    for (const auto& [k, v] : m) {
        std::cout << k << ": " << v << ", ";
    }
    std::cout << std::endl;
    return 0;
}
```

注意：使用 Range-based for 时不同类型对应着不同的传参方式：
```
// 传值遍历，拷贝 pair，一般不推荐
for (auto kv : m)

// 传引用，可以修改 mapped 值，不能改 key
for (auto& kv : m)
    kv.second += 1;

// 常量引用，只读，首选
for (const auto& kv : m)
```

# 添加接口

`insert` / `emplace`：key 已存在则插入失败，旧值不变。
`operator[]` / `insert_or_assign`：key 已存在则更新 mapped 值。

示例代码：
```
int main() {
    std::unordered_map<int, std::string> m;

    auto r1 = m.emplace(1, "a");
    std::cout << "emplace 1: " << r1.second << ", " << m[1] << std::endl;

    auto r2 = m.emplace(1, "b"); // key 已存在，失败
    std::cout << "emplace 1: " << r2.second << ", " << m[1] << std::endl;

    m[1] = "c";                  // 更新已有 key
    std::cout << "operator[]: " << m[1] << std::endl;

    m.insert_or_assign(1, "d");  // 已存在则赋值
    m.insert_or_assign(2, "e");  // 不存在则插入
    std::cout << "1: " << m[1] << ", 2: " << m[2] << std::endl;
    return 0;
}
```

运行结果：
```
emplace 1: 1, a
emplace 1: 0, a
operator[]: c
1: d, 2: e
```

`try_emplace` 只在 key 不存在时才构造 mapped 值，避免“先构造再发现插不进去”。

```
m.try_emplace(1, "no-overwrite");
```

对象很大时，mapped 可以存智能指针：
```
int main() {
    std::unordered_map<int, std::unique_ptr<MyClass>> m;
    auto ptr = std::make_unique<MyClass>(10);
    m.emplace(1, std::move(ptr));
    std::cout << "ptr: " << ptr.get() << std::endl; // 输出 0
    return 0;
}
```

# 删除接口

使用 `erase(key)` 按 key 删除，返回删除的元素个数（0 或 1）。
使用 `erase(it)` 按迭代器删除，返回下一个有效迭代器。
使用 `clear()` 清空所有元素，桶数量是否收缩取决于实现，不要假设 capacity 会变小。

示例代码：
```
int main() {
    std::unordered_map<int, int> m;
    for (int i = 0; i < 5; ++i) {
        m.emplace(i, i * 10);
    }

    std::cout << "erase(2): " << m.erase(2) << std::endl;
    std::cout << "erase(9): " << m.erase(9) << std::endl;

    if (auto it = m.find(3); it != m.end()) {
        m.erase(it);
    }

    for (const auto& [k, v] : m) {
        std::cout << k << ": " << v << ", ";
    }
    std::cout << std::endl;
    return 0;
}
```

遍历时删除某个元素，必须用 `erase` 的返回值更新迭代器：
```
int main() {
    std::unordered_map<int, int> m;
    for (int i = 0; i < 5; ++i) {
        m.emplace(i, i);
    }

    for (auto it = m.begin(); it != m.end(); ) {
        if (it->first % 2 == 0) {
            std::cout << "Delete: " << it->first << std::endl;
            it = m.erase(it);
        } else {
            ++it;
        }
    }

    for (const auto& [k, v] : m) {
        std::cout << k << ": " << v << ", ";
    }
    std::cout << std::endl;
    return 0;
}
```

注意：erase(it) 自动返回下一个有效迭代器，不要再执行 `++it`。range-based for 遍历时不要 erase 当前元素。

# 自定义 key

内置类型、string 可以直接当 key。自定义类型必须同时提供：
+ 哈希函数（`std::hash` 特化，或作为模板参数传入）
+ 相等比较（`operator==` 或 `equal_to`）

示例代码：
```
#include <iostream>
#include <unordered_map>

struct Point {
    int x;
    int y;
    bool operator==(const Point& other) const {
        return x == other.x && y == other.y;
    }
};

struct PointHash {
    std::size_t operator()(const Point& p) const {
        return std::hash<int>{}(p.x) ^ (std::hash<int>{}(p.y) << 1);
    }
};

int main() {
    std::unordered_map<Point, int, PointHash> m;
    m[{1, 2}] = 10;
    std::cout << m.at({1, 2}) << std::endl;
    return 0;
}
```

哈希只影响落在哪个桶，相等比较才决定是不是同一个 key。两个 key 哈希相同但 `==` 为 false，会进同一桶的不同节点（冲突）。两个 key `==` 为 true，必须有相同哈希，否则找不到。

# 使用场景

适合使用的场景：
+ 按 key 高频查找、插入、删除，不关心顺序。
+ 统计计数、去重、缓存、索引。

不适合使用的场景：
+ 需要按 key 有序遍历，改用 std::map。
+ key 很难写出均匀哈希，冲突严重时退化，查找接近链表。
+ 需要稳定的迭代顺序，或对迭代器失效非常敏感。

# 使用技巧

std::unordered_map 使用的 3 个核心经验：
+ 提前 reserve：大概知道元素数量时先 `reserve(n)`，避免插入过程中多次 rehash，迭代器也不容易莫名失效。
+ 查询不要用 `operator[]`：只读查找用 `find` / `at` / `count`，避免把不存在的 key 插进去。
+ 插入优先 emplace / try_emplace：减少临时 pair 的构造；更新已有值用 `insert_or_assign`。
