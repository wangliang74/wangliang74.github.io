# 说明

lambda 是 C++11 引入的匿名函数对象，适合写短小的回调、比较器和算法谓词，不必单独定义一个函数或仿函数类。

编译器会为每个 lambda 生成一个独一无二的类：捕获的变量变成成员，函数体变成 `operator()`。因此 lambda 可以像对象一样拷贝、移动、保存。

基本形态：
```
[捕获列表](参数列表) -> 返回类型 { 函数体 }
```

返回类型常常可以省略，由编译器根据 return 推导。

# 最简形式

示例代码：
```
#include <iostream>

int main() {
    auto add = [](int x, int y) {
        return x + y;
    };
    std::cout << add(1, 2) << std::endl;
    return 0;
}
```

运行结果：
```
3
```

没有捕获时，lambda 可以转换成函数指针：
```
int (*fp)(int, int) = [](int x, int y) { return x + y; };
```

一旦捕获了变量，就不能再转成普通函数指针。

# 捕获列表

捕获决定 lambda 能使用哪些外部变量，以及按值还是按引用。

（1）按值捕获 `[=]` 或 `[x]`

拷贝一份到 lambda 对象里，外部变量后来怎么改，lambda 里看到的仍是捕获时的值。
```
int main() {
    int x = 1;
    auto f = [x]() {
        std::cout << "x: " << x << std::endl;
    };
    x = 100;
    f();
    return 0;
}
```

运行结果：
```
x: 1
```

（2）按引用捕获 `[&]` 或 `[&x]`

lambda 里用的是外部变量本身，外部改了，lambda 里也能看到。
```
int main() {
    int x = 1;
    auto f = [&x]() {
        std::cout << "x: " << x << std::endl;
    };
    x = 100;
    f();
    return 0;
}
```

运行结果：
```
x: 100
```

注意：按引用捕获时，lambda 的寿命不能超过被引用的变量。把引用捕获的 lambda 存起来，原变量已经销毁，就是悬空引用。

（3）混合捕获
```
int a = 1, b = 2;
auto f = [=, &b]() {      // 默认按值，b 按引用
    // a 是拷贝，b 是引用
};
auto g = [&, a]() {       // 默认按引用，a 按值
};
```

（4）捕获 this
```
class MyClass {
public:
    void Show() {
        auto f = [this]() {
            std::cout << "a: " << a << std::endl;
        };
        f();
    }
    int a = 10;
};
```

`[this]` 捕获的是指针，对象销毁后不要再调用这个 lambda。C++17 可以用 `[*this]` 按值拷贝整个对象。

（5）移动捕获（C++14）
```
#include <memory>
#include <iostream>

int main() {
    auto ptr = std::make_unique<int>(10);
    auto f = [p = std::move(ptr)]() {
        std::cout << *p << std::endl;
    };
    std::cout << "ptr: " << ptr.get() << std::endl;
    f();
    return 0;
}
```

运行结果：
```
ptr: 0
10
```

# mutable

按值捕获的变量在 lambda 里默认是 const，不能修改。加上 `mutable` 才能改这份拷贝，不会改外部变量。
```
int main() {
    int x = 1;
    auto f = [x]() mutable {
        x += 1;
        std::cout << "inner x: " << x << std::endl;
    };
    f();
    f();
    std::cout << "outer x: " << x << std::endl;
    return 0;
}
```

运行结果：
```
inner x: 2
inner x: 3
outer x: 1
```

# 作为算法谓词

lambda 最常见的用法是配合 STL 算法。

示例代码：
```
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5, 6};

    vec.erase(std::remove_if(vec.begin(), vec.end(), [](int val) {
        return val % 2 == 0;
    }), vec.end());

    for (int v : vec) {
        std::cout << v << " ";
    }
    std::cout << std::endl;
    return 0;
}
```

运行结果：
```
1 3 5 
```

比较器同样可以用 lambda：
```
std::sort(vec.begin(), vec.end(), [](int a, int b) {
    return a > b;
});
```

# 作为入参

（1）模板参数，编译期确定类型，无类型擦除开销，首选。
```
template <typename F>
void ForEach(const std::vector<int>& vec, F fn) {
    for (int v : vec) {
        fn(v);
    }
}

int main() {
    std::vector<int> vec = {1, 2, 3};
    ForEach(vec, [](int v) {
        std::cout << v << " ";
    });
    return 0;
}
```

C++20 也可以写成：
```
void ForEach(const std::vector<int>& vec, auto fn)
```

（2）`std::function`，可以保存、延迟调用，有类型擦除开销。
```
#include <functional>

void ForEach(const std::vector<int>& vec, const std::function<void(int)>& fn) {
    for (int v : vec) {
        fn(v);
    }
}
```

需要把 lambda 存进容器、做成员变量、跨编译单元传递时，用 `std::function`。只是当场调用一次，用模板或 `auto`。

# 泛型 lambda

C++14 起，参数可以用 `auto`，一次定义能处理多种类型：
```
auto print = [](const auto& x) {
    std::cout << x << std::endl;
};

print(1);
print("hello");
```

# 一些注意

+ 捕获列表为空时，不依赖外部状态，最安全。
+ 能按值就不要按引用，避免 lambda 活得比变量长。
+ 循环里按引用捕获循环变量，所有 lambda 可能看到最后一次的值；按值捕获 `[i]` 才能记住当次的 i。
+ 不要默认写 `[=]` 或 `[&]` 一把抓，明确写出要捕获的变量，读代码更清楚。
+ 函数体超过十几行，就写成普通函数，lambda 适合短逻辑。
