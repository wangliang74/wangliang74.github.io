# 说明

C++17 在工程里非常“好用”：结构化绑定、`if constexpr`、`optional` / `string_view`、文件系统、类模板参数推导。很多项目的默认标准从 11/14 升到 17，主要就是为了这些。

# 结构化绑定

把 pair、tuple、数组、聚合结构一次性拆开：
```
#include <unordered_map>
#include <iostream>

int main() {
    std::unordered_map<int, int> m{{1, 10}, {2, 20}};
    for (const auto& [k, v] : m) {
        std::cout << k << ": " << v << std::endl;
    }
    return 0;
}
```

`insert` / `emplace` 的返回值也可以拆：
```
auto [it, ok] = m.emplace(3, 30);
if (ok) {
    std::cout << it->second << std::endl;
}
```

# if / switch 初始化

`if` 和 `switch` 里可以带一条只在该语句内有效的初始化：
```
if (auto it = m.find(1); it != m.end()) {
    std::cout << it->second << std::endl;
}
```

`it` 不会漏到外面，比先定义再判断更干净。

# if constexpr

编译期 if，不满足的分支直接丢掉，不会实例化。写模板时再也不用一堆 SFINAE。
```
#include <type_traits>
#include <iostream>

template <typename T>
void Show(const T& v) {
    if constexpr (std::is_integral_v<T>) {
        std::cout << "int: " << v << std::endl;
    } else {
        std::cout << "other" << std::endl;
    }
}
```

注意是 `if constexpr`，普通 `if` 两个分支都要能编译。

# std::optional

可能有值、可能没有值，比“返回 -1 / 空指针”更清楚。
```
#include <optional>
#include <iostream>

std::optional<int> Find(bool ok) {
    if (!ok) {
        return std::nullopt;
    }
    return 42;
}

int main() {
    if (auto v = Find(true)) {
        std::cout << *v << std::endl;
    }
    return 0;
}
```

取值前先判断，或用 `value_or(0)`。不要对空 optional 直接 `*`。

# std::string_view

只读、不拥有字符串，适合当函数参数，避免无意义的 `std::string` 拷贝。
```
#include <string_view>
#include <iostream>

void Show(std::string_view s) {
    std::cout << s.size() << ": " << s << std::endl;
}

int main() {
    Show("hello");
    std::string t = "world";
    Show(t);
    return 0;
}
```

注意：`string_view` 不延长临时字符串的寿命。不要返回指向局部 `std::string` 的 `string_view`。

# std::variant / std::any

`variant`：一组确定类型里的“或”，访问用 `std::get` / `std::visit`。  
`any`：可以装任意类型，取出时要知道真实类型，少用。

```
#include <variant>
#include <iostream>

int main() {
    std::variant<int, std::string> v = 10;
    std::cout << std::get<int>(v) << std::endl;
    v = "hi";
    std::visit([](const auto& x) { std::cout << x << std::endl; }, v);
    return 0;
}
```

# 文件系统

`<filesystem>` 跨平台处理路径、遍历目录。
```
#include <filesystem>
#include <iostream>

int main() {
    namespace fs = std::filesystem;
    fs::path p = "content/cpp";
    std::cout << fs::absolute(p) << std::endl;
    if (fs::exists(p)) {
        for (const auto& entry : fs::directory_iterator(p)) {
            std::cout << entry.path() << std::endl;
        }
    }
    return 0;
}
```

链接时有的老 GCC 需要 `-lstdc++fs`。

# 类模板参数推导（CTAD）

构造时可以不写模板参数：
```
std::pair p{1, 2.0};          // pair<int, double>
std::vector v{1, 2, 3};       // vector<int>
std::lock_guard lock(mu);
```

# 折叠表达式

变参模板不必再递归：
```
template <typename... Args>
auto Sum(Args... args) {
    return (args + ...);
}

template <typename... Args>
void Print(const Args&... args) {
    (std::cout << ... << args);
}
```

# inline 变量

头文件里可以定义 inline 变量，不必再拆一个 .cpp 放单例。
```
// header
inline int g_count = 0;
```

# 其他常用点

+ `std::size` / `std::empty` / `std::data`：统一拿容器或数组的大小。
+ `std::clamp(v, lo, hi)`：把值限制在区间内。
+ `try_emplace` / `insert_or_assign`：见 [unordered_map](/cpp/unordered_map/)。
+ 拷贝捕获 this 的 lambda：`[*this]`。
+ `[[nodiscard]]`：返回值不该被丢掉，例如错误码。
+ `std::shared_mutex`：读写锁。

# 使用建议

+ 遍历 map 用 `for (const auto& [k, v] : m)`。
+ 查找用 `if (auto it = m.find(k); it != m.end())`。
+ 可空返回值用 `optional`，只读字符串参数用 `string_view`。
+ 模板分支判断用 `if constexpr`。
+ 路径操作用 `<filesystem>`，不要自己拼斜杠。
