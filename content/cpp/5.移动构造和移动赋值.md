# 移动构造函数

使用一个即将结束生命周期的对象（右值）来创建新对象时，会调用移动构造函数。

移动构造函数被调用的常见场景：

（1）使用 `(std::move(obj))` 创建对象
```
MyClass obj2(std::move(obj));
```

（2）使用 `=` 和 `std::move` 创建对象
```
MyClass obj3 = std::move(obj2);
```

（3）使用右值作为函数入参，值传递
```
void func(MyClass obj4) {
    std::cout << "Function:            " << &obj4 << std::endl;
}

int main() {
    MyClass obj;
    func(std::move(obj));
    return 0;
}
```

（4）不开启返回值优化（NRVO）场景下，使用对象作为函数返回值，值传递
```
MyClass func2() {
    MyClass tmp;
    std::cout << "Function:            " << &tmp << std::endl;
    return tmp;
}

int main() {
    MyClass obj5 = func2();
    std::cout << "Return:              " << &obj5 << std::endl;
    return 0;
}
```

编译器默认开启返回值优化（NRVO），直接在 obj5 的内存位置上构造 tmp，也就是说 obj5 和 tmp 的内存地址是相同的，减少了移动，提高了性能。

使用编译选项 `-fno-elide-constructors` 可以关闭返回值优化（NRVO）：
```
g++ -std=c++17 -fno-elide-constructors cpp.cpp -o cpp
```

关闭返回值优化（NRVO）后，编译器会先创建 tmp，然后调用移动构造函数创建 obj5（如果类提供了移动构造）。

（5）将右值传入 std::vector 的 push_back 接口等场景
```
int main() {
    std::vector<MyClass> objs;
    objs.reserve(10);

    objs.push_back(MyClass());
    return 0;
}
```

传入的是临时对象，没有名字，push_back 时判断其是右值，优先调用移动构造函数。

（6）对已有左值使用 `std::move` 后传入 push_back
```
int main() {
    std::vector<MyClass> objs;
    objs.reserve(10);

    MyClass obj;
    objs.push_back(std::move(obj));
    return 0;
}
```

`std::move` 本身不移动任何东西，只是把左值转成右值引用，让编译器匹配移动构造函数。移动完成后，obj 处于有效但未指定的状态，不要再使用它的资源。

## 默认移动构造函数

如果没有自定义移动构造函数，并且没有破坏编译器自动生成的条件，C++ 编译器会自动生成一个默认移动构造函数。

默认移动构造函数执行“成员级移动”：对每个成员调用它自己的移动构造（或在成员不可移动时退化为拷贝）。

哪些情况下，编译器不会生成默认移动构造函数？

当用户定义了析构函数、拷贝构造、拷贝赋值、移动构造、移动赋值中的任意一种函数，编译器就不再生成默认移动构造函数：
```
class Example {
public:
    ~Example();                          // 析构函数
    Example(const Example&);             // 拷贝构造
    Example& operator=(const Example&);  // 拷贝赋值
    Example(Example&&);                  // 移动构造
    Example& operator=(Example&&);       // 移动赋值
};
```

当定义了析构函数等，说明用户希望自己管理对象的资源，编译器不再生成默认移动构造函数。此时传入右值，编译器找不到移动构造，就会回退去找拷贝构造。

示例代码：
```
#include <iostream>
#include <vector>

class MyClass {
public:
    MyClass() : a(0), b(new int(0)) {
        std::cout << "Constructor:         " << this << std::endl;
    }

    MyClass(const MyClass& other)
        : a(other.a), b(other.b != nullptr ? new int(*other.b) : nullptr) {
        std::cout << "Copy constructor:    " << this << std::endl;
    }

    ~MyClass() {
        std::cout << "Destructor:          " << this << std::endl;
        std::cout << "Address of buf:      " << (void*)b << std::endl;
        delete b;
    }

public:
    int a;
    int *b;
};

int main() {
    std::vector<MyClass> objs;
    objs.reserve(10);

    objs.push_back(MyClass());
    return 0;
}
```

运行结果：
```
Constructor:         0x7ffddb788150
Copy constructor:    0x60e000000040
Destructor:          0x7ffddb788150
Address of buf:      0x602000000010
Destructor:          0x60e000000040
Address of buf:      0x602000000030
```

自定义了拷贝构造和析构后，没有默认移动构造，`push_back(MyClass())` 虽然传入右值，仍然走拷贝构造。

析构函数、拷贝构造、拷贝赋值、移动构造、移动赋值通常称为“Rule of Five（五法则）”，如果一个类自定义了其中一个，通常也需要自定义其他四个。

## 自定义移动构造函数

自定义移动构造函数的标准原型：
```
ClassName(ClassName&& other) noexcept;
```

参数是右值引用，不是 const，因为需要改 other，把它持有的资源“偷”过来，并把 other 置成可析构的空状态。

尽量加上 `noexcept`。std::vector 扩容时，只有移动构造是 noexcept，才会用移动搬运旧元素，否则退回拷贝。

只要自定义了移动构造函数，编译器就不再自动生成默认移动构造函数。

自定义移动构造函数的主要原因是：包含 int* 类似的裸指针。

默认移动（如果还能生成）对裸指针也只是复制指针值，两个对象仍可能指向同一块内存。自定义移动构造应：
+ 接管 other.b
+ 把 other.b 置为 nullptr，避免 other 析构时再 delete 一次

正确代码：
```
#include <iostream>
#include <utility>
#include <vector>

class MyClass {
public:
    MyClass() : a(0), b(new int(0)) {
        std::cout << "Constructor:         " << this << std::endl;
    }

    MyClass(const MyClass& other)
        : a(other.a), b(other.b != nullptr ? new int(*other.b) : nullptr) {
        std::cout << "Copy constructor:    " << this << std::endl;
    }

    MyClass(MyClass&& other) noexcept
        : a(other.a), b(other.b) {
        other.b = nullptr;
        other.a = 0;
        std::cout << "Move constructor:    " << this << std::endl;
    }

    ~MyClass() {
        std::cout << "Destructor:          " << this << std::endl;
        std::cout << "Address of buf:      " << (void*)b << std::endl;
        delete b;
    }

public:
    int a;
    int *b;
};

int main() {
    std::vector<MyClass> objs;
    objs.reserve(10);

    objs.push_back(MyClass());
    return 0;
}
```

运行结果：
```
Constructor:         0x7ffdd468afa0
Move constructor:    0x60e000000040
Destructor:          0x7ffdd468afa0
Address of buf:      0
Destructor:          0x60e000000040
Address of buf:      0x602000000010
```

临时对象被移动进 vector 后，临时对象的 b 变成空指针，析构时不再释放那块内存；真正的缓冲区只由 vector 里的对象释放一次。

对已有对象使用 `std::move`：
```
int main() {
    MyClass obj;
    MyClass obj2(std::move(obj));
    std::cout << "obj.b:               " << (void*)obj.b << std::endl;
    std::cout << "obj2.b:              " << (void*)obj2.b << std::endl;
    return 0;
}
```

运行结果（地址随运行变化）：
```
Constructor:         0x7ffe38660900
Move constructor:    0x7ffe38660930
obj.b:               0
obj2.b:              0x602000000010
Destructor:          0x7ffe38660930
Address of buf:      0x602000000010
Destructor:          0x7ffe38660900
Address of buf:      0
```

# 移动赋值函数

使用一个右值对另外一个已有对象进行赋值时，会调用移动赋值函数。

移动赋值函数和移动构造函数的区别在于：被赋值的对象是否已创建：

```
MyClass obj2 = std::move(obj); // 移动构造

obj2 = std::move(obj);         // 移动赋值
```

自定义移动赋值函数的原型：
```
ClassName& operator=(ClassName&& other) noexcept;
```

它是赋值运算符重载，返回 *this，支持连续赋值。实现时通常：
+ 判断自赋值 `this != &other`
+ 释放本对象当前持有的资源
+ 接管 other 的资源
+ 把 other 置空
+ 返回 *this

示例代码：
```
#include <iostream>
#include <utility>

class MyClass {
public:
    MyClass() : a(0), b(new int(0)) {
        std::cout << "Constructor:         " << this << std::endl;
    }

    MyClass(MyClass&& other) noexcept
        : a(other.a), b(other.b) {
        other.b = nullptr;
        other.a = 0;
        std::cout << "Move constructor:    " << this << std::endl;
    }

    MyClass& operator=(MyClass&& other) noexcept {
        if (this != &other) {
            delete b;
            a = other.a;
            b = other.b;
            other.b = nullptr;
            other.a = 0;
        }
        std::cout << "Move assignment:     " << this << std::endl;
        return *this;
    }

    ~MyClass() {
        std::cout << "Destructor:          " << this << std::endl;
        delete b;
    }

public:
    int a;
    int *b;
};

int main() {
    MyClass obj1;
    MyClass obj2;
    obj2 = std::move(obj1);
    std::cout << "obj1.b:              " << (void*)obj1.b << std::endl;
    std::cout << "obj2.b:              " << (void*)obj2.b << std::endl;
    return 0;
}
```

运行结果：
```
Constructor:         0x7ffe38660900
Constructor:         0x7ffe38660920
Move assignment:     0x7ffe38660920
obj1.b:              0
obj2.b:              0x602000000010
Destructor:          0x7ffe38660920
Destructor:          0x7ffe38660900
```

如果没有自定义移动赋值函数，且编译器仍会生成默认移动赋值，则逐个成员移动赋值。如果成员是裸指针，默认移动赋值往往只是浅拷贝指针，可能导致重复释放。自定义了拷贝赋值或析构后，默认移动赋值通常也不会再生成，右值赋值会退化成拷贝赋值。

# 一些总结

## 拷贝和移动怎么选

编译器按参数是不是右值来选：
```
MyClass obj2(obj);            // 左值 -> 拷贝构造
MyClass obj3(std::move(obj)); // 右值 -> 移动构造
obj2 = obj;                   // 左值 -> 拷贝赋值
obj2 = std::move(obj);        // 右值 -> 移动赋值
```

没有可用的移动函数时，右值会回退到拷贝。没有可用的拷贝函数时（例如 unique_ptr），左值不能拷贝，只能 `std::move`。

## 成员变量是类对象

如果类成员变量的类型也是一个类：

默认移动构造会逐个移动成员，调用成员的移动构造函数。

成员是 `std::string`、`std::unique_ptr` 时，移动通常只是转移内部指针，代价很低。

成员是裸指针时，必须自己写移动，并把源指针置空。

## 尽量不要使用裸指针

不要在 C++ 项目中使用裸指针，特别是作为成员变量。

一旦拥有裸指针类型的成员变量，就需要自定义析构、拷贝构造、拷贝赋值、移动构造、移动赋值，避免内存泄漏、重复释放。

裸指针可以使用 unique_ptr 等智能指针代替。unique_ptr 只能移动、不能拷贝，包含 unique_ptr 成员的类，默认拷贝会被删除，默认移动通常可用。

发生重复释放风险的代码：
```
class MyClass {
public:
    MyClass(int value) : a(new int(value)) {}
    ~MyClass() { delete a; }

private:
    int *a;
};
```

交给智能指针后，移动由 unique_ptr 自己完成：
```
#include <memory>

class MyClass {
public:
    MyClass(int value) : a(std::make_unique<int>(value)) {}

private:
    std::unique_ptr<int> a;
};
```

## 尽量不要自定义五法则

尽量不要自定义析构函数、拷贝构造、拷贝赋值、移动构造、移动赋值函数，让编译器自动生成，即 Rule of Zero（零法则）。

除非对象持有原始资源（裸指针、文件句柄等），需要手动释放，才自定义析构函数。如果定义了其中任意一个，通常也需要自定义其他四个。

自定义移动时记住两件事：
+ 把资源指针从 other 拿走后，把 other 置空，保证 other 析构安全；
+ 移动构造、移动赋值加上 noexcept，方便 vector 等容器走移动而不是拷贝。
