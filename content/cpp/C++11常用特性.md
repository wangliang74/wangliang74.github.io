# 说明

C++11 是现代 C++ 的分界线。日常开发里用得最多的是：类型推导、范围 for、智能指针、移动语义、lambda、统一初始化、`nullptr`，以及一批标准库容器和线程设施。

更细的专题见：[lambda](/cpp/lambda/)、[unique_ptr](/cpp/unique_ptr/)、[shared_ptr](/cpp/shared_ptr/)、[移动构造和移动赋值](/cpp/移动构造和移动赋值/)、[noexcept](/cpp/noexcept/)、[default和delete](/cpp/default和delete/)、[unordered_map](/cpp/unordered_map/)。

# auto

用 `auto` 让编译器根据初始化表达式推导类型，少写冗长的迭代器类型。
```
int main() {
    auto x = 10;          // int
    auto y = 3.14;        // double
    const auto& z = x;    // const int&
    return 0;
}
```

注意：`auto` 会丢掉顶层 const 和引用，需要引用时写成 `auto&` 或 `const auto&`。没有初始值不能用 `auto`。

# 范围 for

```
int main() {
    std::vector<int> vec = {1, 2, 3};
    for (const auto& v : vec) {
        std::cout << v << " ";
    }
    return 0;
}
```

遍历容器或数组时首选。只读用 `const auto&`，要改元素用 `auto&`，不要无故写 `auto v` 触发拷贝。

# nullptr

空指针用 `nullptr`，不要用 `NULL` 或 `0`。`nullptr` 的类型是 `std::nullptr_t`，不会和整型重载打架。
```
void Show(int) { std::cout << "int" << std::endl; }
void Show(int*) { std::cout << "int*" << std::endl; }

int main() {
    Show(nullptr); // 走 int*
    return 0;
}
```

# 统一初始化

花括号可以初始化几乎所有类型：
```
int a{10};
std::vector<int> vec{1, 2, 3};
MyClass obj{1};
```

窄化转换会被拒绝，`int x{3.14};` 无法编译。`std::initializer_list` 让构造函数接收一串同类型值。

# enum class

带作用域的枚举，不会泄漏到外围，也不能和 int 隐式互转。
```
enum class Color { Red, Green, Blue };

int main() {
    Color c = Color::Red;
    // int n = c;          // 错误
    int n = static_cast<int>(c);
    return 0;
}
```

# override / final

`override` 明确这是重写虚函数，签名写错会编译失败。`final` 禁止再被继承或再被重写。
```
struct Base {
    virtual void Show() const {}
};
struct Derived : Base {
    void Show() const override {}
};
```

# 智能指针与移动

资源用 `unique_ptr` / `shared_ptr` 管理，不要裸 `new` / `delete`。所有权转移用 `std::move`。

```
auto ptr = std::make_shared<MyClass>(1);
auto uniq = std::unique_ptr<MyClass>(new MyClass(1)); // C++11 还没有 make_unique
```

`make_unique` 是 C++14 才进入标准库，C++11 项目里可以自己写一个，或继续用 `unique_ptr<T>(new T(...))`。

# lambda

```
auto add = [](int x, int y) { return x + y; };
std::sort(vec.begin(), vec.end(), [](int a, int b) { return a < b; });
```

捕获、`mutable`、当作算法谓词，见 [lambda](/cpp/lambda/)。

# constexpr / static_assert

`constexpr` 函数可以在编译期求值（C++11 限制较严，函数体基本只能有一个 return）。
```
constexpr int Square(int x) { return x * x; }
static_assert(Square(3) == 9, "ok");
```

`static_assert` 在编译期断言，失败直接编译错误，比运行到一半再 assert 更早暴露问题。

# decltype

根据表达式得到类型，常和 `auto` 一起写后置返回类型：
```
template <typename T, typename U>
auto Add(T a, U b) -> decltype(a + b) {
    return a + b;
}
```

# 右值引用与完美转发

`T&&` 在模板里是万能引用。配合 `std::forward` 把参数原样转交给下一个函数，避免多余拷贝。
```
template <typename T>
void Wrapper(T&& v) {
    Show(std::forward<T>(v));
}
```

# 变参模板

```
void Print() {}

template <typename T, typename... Args>
void Print(const T& first, const Args&... rest) {
    std::cout << first << " ";
    Print(rest...);
}
```

C++11 用递归展开参数包；C++17 的折叠表达式更短。

# 线程库

`<thread>` / `<mutex>` / `<lock_guard>` / `<future>` 进入标准库，不必只依赖平台 API。
```
#include <thread>
#include <mutex>
#include <iostream>

std::mutex mu;

void Work(int id) {
    std::lock_guard<std::mutex> lock(mu);
    std::cout << "id: " << id << std::endl;
}

int main() {
    std::thread t1(Work, 1);
    std::thread t2(Work, 2);
    t1.join();
    t2.join();
    return 0;
}
```

锁必须用 RAII（`lock_guard` / `unique_lock`），不要手写 `lock()` / `unlock()`。

# 常用标准库补充

+ `std::array`：栈上固定数组，能当容器用。
+ `std::tuple` / `std::tie`：打包多个返回值。
+ `std::unordered_map` / `unordered_set`：哈希表。
+ `std::chrono`：时间点、时长。
+ `std::regex`：正则（实现性能一般，简单匹配可用）。
+ `std::move` / `std::forward` / `std::swap`。

# 使用建议

+ 空指针写 `nullptr`，范围循环写 `const auto&`。
+ 资源用智能指针，五法则能不写就不写。
+ 重写虚函数加上 `override`。
+ 枚举用 `enum class`。
+ 先把 C++11 这几样用熟，再叠加 14/17/20。
