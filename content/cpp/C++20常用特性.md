# 说明

C++20 体量很大：概念、Ranges、协程、模块、三路比较、`span`、日历。工程里最先能落地的通常是：`concept`、`<=>`、指定初始化、`span`、`std::format`（视编译器）、Ranges 里的视图。

模块和协程改动大，工具链和项目习惯还在跟，下面只记常用用法。

# 概念（concepts）

给模板参数加约束，报错更短，意图更清楚。
```
#include <concepts>
#include <iostream>

template <std::integral T>
T Add(T a, T b) {
    return a + b;
}

int main() {
    std::cout << Add(1, 2) << std::endl;
    // Add(1.5, 2.5); // 不满足 integral，编译失败
    return 0;
}
```

也可以自己写 concept：
```
template <typename T>
concept HasSize = requires(T t) {
    { t.size() } -> std::convertible_to<std::size_t>;
};

void Show(const HasSize auto& c) {
    std::cout << c.size() << std::endl;
}
```

`requires` 描述“这个类型必须能干什么”。以前靠 SFINAE 的代码，能换成 concept 就换。

# 三路比较 <=>

一次定义，自动生成 `==` `!=` `<` `<=` `>` `>=`（按成员依次比）。
```
#include <compare>

struct Point {
    int x;
    int y;
    auto operator<=>(const Point&) const = default;
};

int main() {
    Point a{1, 2}, b{1, 3};
    bool less = a < b;     // true
    bool eq = a == b;      // false
    return 0;
}
```

只生成相等、不要大小比较时，可以只 `= default` `operator==`。

# 指定初始化

按成员名初始化聚合类型，顺序可以和声明不一致，漏写的成员值初始化。
```
struct Config {
    int port;
    bool debug;
};

Config c{.port = 8080, .debug = true};
```

比“对着位置填 0”更不容易填错。

# std::span

不拥有元素的连续视图，函数既能收 `vector` 也能收数组。
```
#include <span>
#include <iostream>
#include <vector>

void Show(std::span<const int> s) {
    for (int v : s) {
        std::cout << v << " ";
    }
    std::cout << std::endl;
}

int main() {
    int arr[] = {1, 2, 3};
    std::vector<int> vec{4, 5, 6};
    Show(arr);
    Show(vec);
    return 0;
}
```

和 `string_view` 类似：不延长底层容器寿命，不要返回指向局部 `vector` 的 `span`。

# Ranges

不必成对写 `begin` / `end`，并且可以管道式组合视图。
```
#include <ranges>
#include <vector>
#include <iostream>

int main() {
    std::vector<int> vec{1, 2, 3, 4, 5, 6};
    for (int v : vec | std::views::filter([](int x) { return x % 2 == 0; })
                     | std::views::transform([](int x) { return x * x; })) {
        std::cout << v << " ";
    }
    return 0;
}
```

运行结果：
```
4 16 36 
```

`filter` / `transform` / `take` / `drop` / `reverse` 最常用。视图是惰性的，真正遍历时才计算。

# consteval / constinit

+ `constexpr`：可以编译期，也可以运行期。
+ `consteval`：必须编译期求值，当函数当运行期用会编译失败。
+ `constinit`：要求静态变量初始化发生在编译期，避免动态初始化顺序问题。

```
consteval int Square(int x) { return x * x; }
constexpr int a = Square(3);
```

# 日历与时区

`<chrono>` 补了年、月、日、weekday，写日期比自己算时间戳清楚：
```
#include <chrono>
#include <iostream>

int main() {
    using namespace std::chrono;
    year_month_day day = 2026y / 10 / 24;
    std::cout << static_cast<int>(day.year()) << std::endl;
    return 0;
}
```

时区数据库依赖平台，有的环境还不完整。

# std::format

类型安全的格式化，比手写 `<<` 和 `snprintf` 更干净（MSVC / 新 GCC / Clang 支持情况不同，老环境可能要用 {fmt}）。
```
#include <format>
#include <iostream>

int main() {
    std::cout << std::format("a={} b={:.2f}\n", 10, 3.14159);
    return 0;
}
```

# 协程（了解即可）

`co_await` / `co_yield` / `co_return` 把函数变成可暂停的状态机。标准库只提供底层机制，`task` / `generator` 通常用第三方（cppcoro、asio）。没有现成框架时，不要自己从零造协程类型。

# 模块（了解即可）

```
export module hello;
export void Hi();
```

用来替代头文件、加快编译。CMake、发行版、第三方库支持仍不齐，多数业务仓库还是头文件 + 预编译头。

# 其他常用点

+ `using enum Color;`：在作用域里直接写 `Red`，不用 `Color::Red`。
+ `likely` / `unlikely`：给分支预测提示，热点路径才值得标。
+ `std::jthread`：析构时自动 join，比裸 `std::thread` 安全。
+ `std::source_location`：打日志时拿文件名、行号。
+ 模板形参可以是浮点、字面量类（NTTP 放宽）。
+ `std::atomic` 共享指针、`std::stop_token` 协作式取消。

# 使用建议

+ 模板约束优先 concept，少写 `enable_if`。
+ 比较运算能 `= default` `<=>` 就不要手写六套。
+ 函数入参是连续只读区间，考虑 `span` / `string_view`。
+ 过滤、变换序列，试试 Ranges 管道，比手写循环短。
+ 协程、模块等生态成熟后再上，不必为了“用上 20”强行引入。
