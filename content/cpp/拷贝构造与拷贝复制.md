# 拷贝构造函数

使用一个已有对象来创建新对象时，会调用拷贝构造函数。

拷贝构造函数被调用的常见场景：

（1）使用 `(obj)` 创建对象
```
MyClass obj2(obj);
```

（2）使用 `=` 创建对象
```
MyClass obj3 = obj2;
```

（3）使用对象作为函数入参，值传递
```
void func(MyClass obj4) {
    std::cout << "Function:            " << &obj4 << std::endl;
}
```

（4）不开启返回值优化（NRVO）场景下，使用对象作为函数返回值，值传递
```
MyClass func2() {
    MyClass tmp;
    std::cout << "Function:            " << &tmp << std::endl;
    return tmp;
}

int main() {
    MyClass obj;
    MyClass obj5 = func2();
    std::cout << "Return:              " << &obj5 << std::endl;
    return 0;
}
```

编译器默认开启返回值优化（NRVO），直接在 obj5 的内存位置上构造 tmp，也就是说 obj5 和 tmp 的内存地址是相同的，减少了拷贝，提高了性能。

使用编译选项 `-fno-elide-constructors` 可以关闭返回值优化（NRVO）：
```
g++ -std=c++17 -fno-elide-constructors cpp.cpp -o cpp
```

关闭返回值优化（NRVO）后，编译器会先创建 tmp，然后调用拷贝构造函数创建 obj5。

（5）将左值传入 std::vector 的 push_back 接口等场景
```
int main() {
    std::vector<MyClass> objs;
    objs.reserve(10);

    MyClass obj;
    objs.push_back(obj);
    return 0;
}
```

传入的 obj 有名字，还可以在 main 函数里使用，push_back 时判断其是左值，调用拷贝构造函数。

（6）没有自定义移动构造函数，同时破坏了编译器自动生成默认移动构造函数，将右值传入 std::vector 的 push_back 接口等场景

当你传入右值，编译器找不到移动构造数，就会回退去找拷贝构造数。

示例代码：
```
#include <iostream>
#include <stdexcept>
#include <string>
#include <utility>
#include <vector>

class MyClass {
public:
    MyClass() : a(0), b(new int(0)) {
        std::cout << "Constructor:         " << this << std::endl;
    }

    MyClass(const MyClass& other)
        : a(other.a), b(other.b != nullptr ? new int(*other.b) : nullptr) {
        std::cout << "Copy constructor:    " << this << std::endl;
    }

    ~MyClass() {
        std::cout << "Destructor:          " << this << std::endl;
        std::cout << "Address of member a: " << &a << std::endl;
        std::cout << "Address of member b: " << &b << std::endl;
        std::cout << "Address of buf:      " << (void*)b << std::endl;
        delete b;
    }

public:
    int a;
    int *b;
};

int main() {
    std::vector<MyClass> objs;
    objs.reserve(10);

    objs.push_back(MyClass());
    return 0;
}
```

运行结果：
```
Constructor:         0x7ffddb788150
Copy constructor:    0x60e000000040
Destructor:          0x7ffddb788150
Address of member a: 0x7ffddb788150
Address of member b: 0x7ffddb788158
Address of buf:      0x602000000010
Destructor:          0x60e000000040
Address of member a: 0x60e000000040
Address of member b: 0x60e000000048
Address of buf:      0x602000000030
```

哪些情况下，编译器不会生成默认移动构造函数呢？

当用户定义了析构函数、拷贝构造、拷贝赋值、移动构造、移动赋值中的任意一种函数，编译器就不再生成默认移动构造函数：
```
class Example {
public:
    ~Example();                          // 析构函数
    Example(const Example&);             // 拷贝构造
    Example& operator=(const Example&);  // 拷贝赋值
    Example(Example&&);                  // 移动构造
    Example& operator=(Example&&);       // 移动赋值
};
```

当定义了析构函数等，说明用户希望自己管理对象的资源，而不是编译器自动管理，所以编译器不再生成默认移动构造函数。

例如类包含裸指针成员，编译器生成的默认析构函数不会释放指针指向的内存，用户会自定义析构函数，默认移动构造函数也无法正确的移动指针指向的内存，所以编译器不会生成默认移动构造函数。

析构函数、拷贝构造、拷贝赋值、移动构造、移动赋值通常称为“Rule of Five（五法则）”，如果一个类自定义了其中一个，通常也需要自定义其他四个，表示用户手动管理这个类的所有资源。


## 默认拷贝构造函数

如果没有自定义拷贝构造函数，C++编译器会自动生成一个默认拷贝构造函数。

默认拷贝构造函数执行“浅拷贝”（Shallow Copy），即逐个成员地进行复制。

实例代码：
```
#include <iostream>

class MyClass {
public:
    MyClass() : a(0), b("default") {
        std::cout << "Constructor:         " << this << std::endl;
    }
    ~MyClass() {
        std::cout << "Destructor:          " << this << std::endl;
        std::cout << "Address of member a: " << &a << std::endl;
        std::cout << "Address of member b: " << &b << std::endl;
        std::cout << "Address of char buf: " << (void*)b.data() << std::endl;
    }

public:
    int a;
    std::string b;
};

int main() {
    MyClass obj;
    MyClass obj2(obj);
    MyClass obj3 = obj2;
    return 0;
}
```

运行结果：
```
Constructor:         0x7ffe38660900
Destructor:          0x7ffe38660960
Address of member a: 0x7ffe38660960
Address of member b: 0x7ffe38660968
Address of char buf: 0x7ffe38660978
Destructor:          0x7ffe38660930
Address of member a: 0x7ffe38660930
Address of member b: 0x7ffe38660938
Address of char buf: 0x7ffe38660948
Destructor:          0x7ffe38660900
Address of member a: 0x7ffe38660900
Address of member b: 0x7ffe38660908
Address of char buf: 0x7ffe38660918
```

构造函数只被调用了一次，析构函数被调用了三次，有两个对象是调用默认拷贝构造函数创建的。

对于 std::string 类型成员，编译器会调用 std::string 的拷贝构造函数来创建成员。

对于自定义类的成员，编译器会调用该成员的类拷贝构造函数来创建成员。

尽量不要定义裸指针类型的成员变量：
（1）可能忘记在析构函数里调用 delete, 导致内存泄漏；
（2）默认拷贝构造函数执行浅拷贝，两个对象共用同一个裸指针，导致重复释放。

## 自定义拷贝构造函数

自定义拷贝构造函数的标准原型：
```
ClassName(const ClassName& other);
```

只要自定义了拷贝构造函数，编译器就不再自动生成默认拷贝构造函数。

自定义拷贝构造函数的主要原因是：包含 int* 类似的裸指针。

由于裸指针的类型不是类，没有拷贝构造函数，只会复制指针变量本身，不会复制指针指向的内存，导致一份内存可能被多个对象使用，从而导致重复释放等问题。

问题代码：
```
#include <iostream>

class MyClass {
public:
    MyClass() : a(0) {
        b = new int(0);
        std::cout << "Constructor:         " << this << std::endl;
    }
    ~MyClass() {
        std::cout << "Destructor:          " << this << std::endl;
        std::cout << "Address of member a: " << &a << std::endl;
        std::cout << "Address of member b: " << &b << std::endl;
        std::cout << "Address of buf:      " << (void*)b << std::endl;
        delete b;
    }

public:
    int a;
    int *b;
};

int main() {
    MyClass obj;
    MyClass obj2(obj);
    return 0;
}
```

运行结果：
```
Constructor:         0x7ffff3a00370
Destructor:          0x7ffff3a00390
Address of member a: 0x7ffff3a00390
Address of member b: 0x7ffff3a00398
Address of buf:      0x602000000010
Destructor:          0x7ffff3a00370
Address of member a: 0x7ffff3a00370
Address of member b: 0x7ffff3a00378
Address of buf:      0x602000000010
```

两个对象析构时释放同一块内存，导致内存重复释放。

通过自定义拷贝构造函数，为新对象的指针成员申请新的内存，能够解决该问题。

正确代码：
```
#include <iostream>

class MyClass {
public:
    MyClass() : a(0), b(new int(0)) {
        std::cout << "Constructor:         " << this << std::endl;
    }

    MyClass(const MyClass& other)
        : a(other.a), b(other.b != nullptr ? new int(*other.b) : nullptr) {
        std::cout << "Copy constructor:    " << this << std::endl;
    }

    ~MyClass() {
        std::cout << "Destructor:          " << this << std::endl;
        std::cout << "Address of member a: " << &a << std::endl;
        std::cout << "Address of member b: " << &b << std::endl;
        std::cout << "Address of buf:      " << (void*)b << std::endl;
        delete b;
    }

public:
    int a;
    int *b;
};

int main() {
    MyClass obj;
    MyClass obj2(obj);
    return 0;
}
```

运行结果：
```

Copy constructor:    0x7ffdd468afc0
Destructor:          0x7ffdd468afc0
Address of member a: 0x7ffdd468afc0
Address of member b: 0x7ffdd468afc8
Address of buf:      0x602000000030
Destructor:          0x7ffdd468afa0
Address of member a: 0x7ffdd468afa0
Address of member b: 0x7ffdd468afa8
Address of buf:      0x602000000010
```

# 拷贝赋值函数

使用一个已有对象对另外一个已有对象进行赋值时，会调用拷贝赋值函数。

拷贝赋值函数和拷贝构造函数的区别在于：被赋值的对象是否已创建：

```
MyClass obj2 = obj; // 拷贝构造

obj2 = obj;         // 拷贝复制
```

自定义拷贝赋值函数的原型：
```
ClassName& operator=(const ClassName& other);
```

它是赋值运算符重载，返回值 *this，支持 `a = b = c` 连续赋值。

示例代码：
```
#include <iostream>

class MyClass {
public:
    MyClass() : a(0), b(new int(0)) {
        std::cout << "Constructor:         " << this << std::endl;
    }

    MyClass& operator=(const MyClass& other) {
        if (this != &other) {
            // 先完成可能抛出异常的分配
            int* new_b = (other.b != nullptr) ? new int(*other.b) : nullptr;
            // 再释放原来的内存
            delete b;
            // 赋值
            a = other.a;
            b = new_b;
        }
        return *this;
    }

    ~MyClass() {
        std::cout << "Destructor:          " << this << std::endl;
        delete b;
    }

public:
    int a;
    int *b;
};

int main() {
    MyClass obj1;
    MyClass obj2;
    obj2 = obj1;
    return 0;
}
```

如果没有自定义拷贝赋值函数，编译器也会生成默认拷贝赋值函数，逐个成员调用成员的拷贝赋值，覆盖本对象成员。

如果成员是裸指针，默认拷贝赋值函数也只是浅拷贝，可能导致内存重复释放等问题。


# 一些总结

## 成员变量是类对象

如果类成员变量的类型也是一个类：

创建类对象时，编译器先按声明顺序调用成员的构造函数，再调用本类的构造函数。

释放类对象时，编译器先调用本类的析构函数，再逆序调用成员的析构函数。

编译器生成的默认拷贝构造函数，会逐个拷贝成员，调用成员的拷贝构造函数。

## 尽量不要使用裸指针

不要在 C++ 项目中使用裸指针，特别是作为成员变量。

一旦拥有裸指针类型的成员变量，就需要自定义析构函数、拷贝构造等，避免内存泄漏、重复释放。

裸指针可以使用 unique_ptr 等智能指针代替。

unique_ptr 等智能指针是类模板，std::unique_ptr<int>就是一个具体的类，拥有自己的析构函数。如果一个类包含 std::unique_ptr<int> 类型的成员变量，类对象析构时，编译器会自动调用 std::unique_ptr<int> 成员的析构函数，释放指针指向的内存。

发生内存泄漏的代码：
```
#include <iostream>
#include <memory>
#include <utility>

class MyClass {
public:
    MyClass(int value) : a(new int(value)) {}

private:
    int *a;
};

int main() {
    MyClass obj(100);
    return 0;
}
```

不会发生内存泄漏的代码：
```
#include <iostream>
#include <memory>
#include <utility>

class MyClass {
public:
    MyClass(int value): a(std::make_unique<int>(value)) {}

private:
    std::unique_ptr<int> a;
};

int main() {
    MyClass obj(100);
    return 0;
}
```

## 尽量不要自定义析构函数

尽量不要自定义析构函数、拷贝构造、拷贝赋值、移动构造、移动赋值函数，让编译器自动生成默认的析构函数、拷贝构造、拷贝赋值、移动构造、移动赋值函数，即 Rule of Zero（零法则）。

除非对象持有原始资源（裸指针、文件句柄等），需要手动释放，才自定义析构函数。如果定义了析构函数、拷贝构造、拷贝赋值、移动构造、移动赋值函数中一个，通常也需要自定义其他四个。
