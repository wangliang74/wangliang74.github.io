# 说明

C++14 是对 C++11 的小修订，没有改语言方向，但补了几处每天都会碰到的缺口：`make_unique`、泛型 lambda、返回类型推导、变量模板、二进制字面量和数字分隔符。

# std::make_unique

C++11 有 `make_shared`，没有标准的 `make_unique`。C++14 补上后，创建独占指针应统一写成：
```
#include <memory>

int main() {
    auto ptr = std::make_unique<MyClass>(1);
    return 0;
}
```

不要再写 `unique_ptr<T>(new T(...))`。`make_unique` 异常安全，也避免手里同时拿着裸 `new`。

# 返回类型推导

普通函数也可以用 `auto` 推导返回类型，不必再写 `-> decltype(...)`。
```
auto Add(int a, int b) {
    return a + b;
}
```

多个 return 的类型必须一致。只返回引用时，要用 `auto&` 或 `decltype(auto)`，否则会变成拷贝。

# decltype(auto)

`auto` 会丢掉引用和顶层 const，`decltype(auto)` 按 `decltype` 规则保留。
```
int global = 10;

auto f1() { return global; }            // 返回 int，拷贝
decltype(auto) f2() { return (global); } // 返回 int&
decltype(auto) f3() { return global; }   // 返回 int
```

封装转发函数、想“返回值和表达式完全同类型”时用 `decltype(auto)`。日常返回值用 `auto` 即可。

# 泛型 lambda

参数可以写成 `auto`，一个 lambda 能处理多种类型。详见 [lambda](/cpp/lambda/)。
```
auto print = [](const auto& x) {
    std::cout << x << std::endl;
};

print(1);
print("hello");
```

# 变量模板

不仅函数、类可以是模板，变量也可以：
```
template <typename T>
constexpr T pi = T(3.1415926535897932385);

float a = pi<float>;
double b = pi<double>;
```

标准库里 `std::is_same_v<T, U>` 这类 `_v` 变量模板从 C++17 开始普及，思路来自这里。

# 二进制字面量与数字分隔符

```
int mask = 0b1010'0001;
long long big = 1'000'000'000;
```

`0b` 写二进制位图更直观。单引号 `'` 只是给数字分组，不影响值，方便读大数。

# [[deprecated]]

标记即将废弃的接口，调用时编译器给警告：
```
[[deprecated("use Bar() instead")]]
void Foo();
```

# std::exchange

把变量换成新值，并返回旧值，移动场景里很常见：
```
#include <utility>

int old = std::exchange(x, 0);
```

自定义移动赋值时，也可以对成员做 `b = std::exchange(other.b, nullptr)`，把源指针置空。

# 放松的 constexpr

C++14 的 `constexpr` 函数可以有局部变量、循环、多个 return，不再限制成“只能一行 return”。编译期计算比 C++11 好写很多。
```
constexpr int Factorial(int n) {
    int r = 1;
    for (int i = 1; i <= n; ++i) {
        r *= i;
    }
    return r;
}

static_assert(Factorial(5) == 120, "ok");
```

# 使用建议

+ 创建 `unique_ptr` 一律 `make_unique`。
+ 短 lambda 用 `auto` 参数，少写重复重载。
+ 函数返回引用时想清楚：`auto` 还是 `decltype(auto)`。
+ 位标志用 `0b`，大数用 `'` 分隔，代码更好读。
