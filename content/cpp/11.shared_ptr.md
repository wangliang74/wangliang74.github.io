## 说明

shared_ptr 共享内存的所有权，可以拷贝，也可以移动。

定义两个 shared_ptr 指针 ptr1 和 ptr2，ptr1 指向内存地址 A，将 ptr1 拷贝给 ptr2 后，ptr1 和 ptr2 同时指向 A，引用计数变为 2。最后一个 shared_ptr 离开作用域时，才会释放 A。

它通过控制块记录引用计数来保证“最后一个所有者负责释放”。拷贝时增加引用计数，移动时只转移所有权，源对象置空，引用计数不变。

## 接口
```
// 创建
std::shared_ptr<MyClass> ptr1 = std::make_shared<MyClass>(1);

// 获取裸指针
ptr1.get()

// 获取引用
*ptr1

// 释放当前所有权，引用计数减 1；减到 0 时释放对象，指针置为空
ptr.reset();

// 当前共享该对象的 shared_ptr 数量
ptr.use_count();
```

优先使用 `std::make_shared` 创建，一次分配对象和控制块，异常安全更好。

## 自动释放

与裸指针相比，shared_ptr 离开作用域时会减少引用计数；引用计数减到 0 时，自动释放其指向的内存。

示例代码：
```
#include <memory>
#include <iostream>

class MyClass {
public:
    explicit MyClass(int value) : a(value) {
        std::cout << "Constructor: " << this << std::endl;
    }
    ~MyClass() {
        std::cout << "Destructor:  " << this << std::endl;
    }
public:
    int a;
};

void Show() {
    std::shared_ptr<MyClass> ptr = std::make_shared<MyClass>(10);
    std::cout << "use_count:   " << ptr.use_count() << std::endl;
    std::cout << "a:           " << ptr->a << std::endl;
}

int main() {
    std::cout << "Before Show()" << std::endl;
    Show();
    std::cout << "After  Show()" << std::endl;
    return 0;
}
```

运行结果：
```
Before Show()
Constructor: 0x602000000010
use_count:   1
a:           10
Destructor:  0x602000000010
After  Show()
```

## 支持拷贝构造和拷贝赋值

拷贝后多个 shared_ptr 指向同一块内存，引用计数加 1。

拷贝构造示例代码：
```
int main() {
    std::shared_ptr<MyClass> ptr1 = std::make_shared<MyClass>(1);
    std::shared_ptr<MyClass> ptr2 = ptr1;
    std::cout << "ptr1:        " << ptr1.get() << std::endl;
    std::cout << "ptr2:        " << ptr2.get() << std::endl;
    std::cout << "use_count:   " << ptr1.use_count() << std::endl;
    return 0;
}
```

运行结果：
```
Constructor: 0x602000000010
ptr1:        0x602000000010
ptr2:        0x602000000010
use_count:   2
Destructor:  0x602000000010
```

按值传入函数也会发生拷贝构造，函数返回后引用计数减 1，对象不一定立刻析构。

示例代码：
```
void Show(std::shared_ptr<MyClass> ptr) {
    std::cout << "ptr :        " << ptr.get() << std::endl;
    std::cout << "use_count:   " << ptr.use_count() << std::endl;
    std::cout << "a:           " << ptr->a << std::endl;
}

int main() {
    std::shared_ptr<MyClass> ptr1 = std::make_shared<MyClass>(1);
    std::cout << "Before Show(), use_count: " << ptr1.use_count() << std::endl;
    Show(ptr1);
    std::cout << "After  Show(), use_count: " << ptr1.use_count() << std::endl;
    std::cout << "ptr1:        " << ptr1.get() << std::endl;
    return 0;
}
```

运行结果：
```
Constructor: 0x602000000010
Before Show(), use_count: 1
ptr :        0x602000000010
use_count:   2
a:           1
After  Show(), use_count: 1
ptr1:        0x602000000010
Destructor:  0x602000000010
```

如果 ptr2 本身已指向另一块内存，拷贝赋值会先让 ptr2 放弃旧对象（引用计数减 1），再共享 ptr1 的对象。

示例代码：
```
void Show() {
    std::shared_ptr<MyClass> ptr1 = std::make_shared<MyClass>(1);
    std::shared_ptr<MyClass> ptr2 = std::make_shared<MyClass>(12);

    ptr2 = ptr1;
    std::cout << "ptr1:        " << ptr1.get() << std::endl;
    std::cout << "ptr2:        " << ptr2.get() << std::endl;
    std::cout << "use_count:   " << ptr1.use_count() << std::endl;
    std::cout << "a:           " << ptr2->a << std::endl;
}

int main() {
    std::cout << "Before Show()" << std::endl;
    Show();
    std::cout << "After  Show()" << std::endl;
    return 0;
}
```

运行结果：
```
Before Show()
Constructor: 0x602000000010
Constructor: 0x602000000030
Destructor:  0x602000000030
ptr1:        0x602000000010
ptr2:        0x602000000010
use_count:   2
a:           1
Destructor:  0x602000000010
After  Show()
```

## 支持移动构造和移动赋值

移动后所有权转移到目标对象，源对象置空，引用计数不变。

示例代码：
```
#include <iostream>
#include <memory>

class MyClass {
public:
    explicit MyClass(int value) : a(value) {
        std::cout << "Constructor: " << this << std::endl;
    }
    ~MyClass() {
        std::cout << "Destructor:  " << this << std::endl;
    }
public:
    int a;
};

void Show() {
    std::shared_ptr<MyClass> ptr1 = std::make_shared<MyClass>(1);
    std::shared_ptr<MyClass> ptr2 = std::move(ptr1);
    std::cout << "ptr1:        " << ptr1.get() << std::endl;
    std::cout << "ptr2:        " << ptr2.get() << std::endl;
    std::cout << "use_count:   " << ptr2.use_count() << std::endl;
    std::cout << "a:           " << ptr2->a << std::endl;
}

int main() {
    std::cout << "Before Show()" << std::endl;
    Show();
    std::cout << "After  Show()" << std::endl;
    return 0;
}
```

运行结果：
```
Before Show()
Constructor: 0x602000000010
ptr1:        0
ptr2:        0x602000000010
use_count:   1
a:           1
Destructor:  0x602000000010
After  Show()
```

执行 `ptr2 = std::move(ptr1);` 后，ptr2 接管对象，ptr1 变成空指针，`use_count` 仍为 1。

如果 ptr2 本身指向内存，移动赋值会先释放其旧对象，再接管 ptr1 的对象。

示例代码：
```
void Show() {
    std::shared_ptr<MyClass> ptr1 = std::make_shared<MyClass>(1);
    std::shared_ptr<MyClass> ptr2 = std::make_shared<MyClass>(12);

    ptr2 = std::move(ptr1);
    std::cout << "ptr1:        " << ptr1.get() << std::endl;
    std::cout << "ptr2:        " << ptr2.get() << std::endl;
    std::cout << "use_count:   " << ptr2.use_count() << std::endl;
    std::cout << "a:           " << ptr2->a << std::endl;
}

int main() {
    std::cout << "Before Show()" << std::endl;
    Show();
    std::cout << "After  Show()" << std::endl;
    return 0;
}
```

运行结果：
```
Before Show()
Constructor: 0x602000000010
Constructor: 0x602000000030
Destructor:  0x602000000030
ptr1:        0
ptr2:        0x602000000010
use_count:   1
a:           1
Destructor:  0x602000000010
After  Show()
```

## 作为入参

(1) 如果函数需要延长对象生命周期、与调用方共享所有权，使用 shared_ptr 作为参数类型（按值传递会增加引用计数）。
示例代码：
```
void Show(std::shared_ptr<MyClass> ptr) {
    std::cout << "ptr :        " << ptr.get() << std::endl;
    std::cout << "use_count:   " << ptr.use_count() << std::endl;
    std::cout << "a:           " << ptr->a << std::endl;
}

int main() {
    std::shared_ptr<MyClass> ptr1 = std::make_shared<MyClass>(1);
    Show(ptr1);
    std::cout << "ptr1:        " << ptr1.get() << std::endl;
    std::cout << "use_count:   " << ptr1.use_count() << std::endl;
    return 0;
}
```

运行结果：
```
Constructor: 0x602000000010
ptr :        0x602000000010
use_count:   2
a:           1
ptr1:        0x602000000010
use_count:   1
Destructor:  0x602000000010
```

(2) 如果只想查看对象属性、调用方法，不涉及生命周期管理，使用 const 裸指针或 const 引用作为参数类型。
示例代码：
```
// 传递裸指针
void Show2(const MyClass *ptr) {
    std::cout << "ptr :        " << ptr << std::endl;
    std::cout << "a:           " << ptr->a << std::endl;
}

// 传递引用
void Show3(const MyClass& obj) {
    std::cout << "ptr :        " << &obj << std::endl;
    std::cout << "a:           " << obj.a << std::endl;
}

int main() {
    std::shared_ptr<MyClass> ptr1 = std::make_shared<MyClass>(1);
    Show2(ptr1.get());
    Show3(*ptr1);
    return 0;
}
```

(3) 不推荐使用 `void func(const std::shared_ptr<MyClass>& ptr)` 只为了读对象。直接传裸指针或引用，表示不涉及生命周期管理。

(4) 需要在函数里改掉调用方持有的 shared_ptr（例如 reset 或换成另一个对象）时，用非 const 的 shared_ptr 引用 `void func(std::shared_ptr<MyClass>& ptr)`。
示例代码：
```
void Show(std::shared_ptr<MyClass>& ptr) {
    ptr.reset();
    std::cout << "ptr :         " << ptr.get() << std::endl;
}

int main() {
    std::shared_ptr<MyClass> ptr1 = std::make_shared<MyClass>(1);
    std::cout << "before, ptr1: " << ptr1.get() << std::endl;
    Show(ptr1);
    std::cout << "after , ptr1: " << ptr1.get() << std::endl;
    return 0;
}
```

运行结果：
```
Constructor:  0x602000000010
before, ptr1: 0x602000000010
Destructor:   0x602000000010
ptr :         0
after , ptr1: 0
```

## 作为返回值

(1) 转交或共享所有权，在函数内部创建 shared_ptr，按值返回。
```
std::shared_ptr<MyClass> Create(int value) {
    auto ptr = std::make_shared<MyClass>(value);

    std::cout << "ptr : " << ptr.get() << std::endl;

    return ptr;
}

int main() {
    std::shared_ptr<MyClass> ptr1 = Create(1);
    std::cout << "ptr1: " << ptr1.get() << std::endl;
    return 0;
}
```

(2) 不转交所有权，shared_ptr 的内存不是在函数内创建，可以返回裸指针。
```
#include <iostream>
#include <memory>

class MyClass2 {};

class MyClass {
public:
    explicit MyClass() {
        a = std::make_shared<MyClass2>();
    }
    MyClass2* GetA() const {
        return a.get();
    }
public:
    std::shared_ptr<MyClass2> a;
};

int main() {
    MyClass obj;
    std::cout << "a: " << obj.GetA() << std::endl;
    return 0;
}
```

注意：

不要返回局部 shared_ptr 的引用或指针，可能导致 use-after-free 问题；
返回局部变量，不需要 std::move，编译器会自动进行返回值优化；
返回全局、成员变量时，拷贝会共享所有权，移动需要 std::move。

## 循环引用

两个对象互相用 shared_ptr 持有对方时，引用计数永远到不了 0，内存不会释放。

示例代码：
```
#include <iostream>
#include <memory>

class B;

class A {
public:
    std::shared_ptr<B> b;
    ~A() { std::cout << "Destructor A" << std::endl; }
};

class B {
public:
    std::shared_ptr<A> a;
    ~B() { std::cout << "Destructor B" << std::endl; }
};

int main() {
    auto pa = std::make_shared<A>();
    auto pb = std::make_shared<B>();
    pa->b = pb;
    pb->a = pa;
    std::cout << "A use_count: " << pa.use_count() << std::endl;
    std::cout << "B use_count: " << pb.use_count() << std::endl;
    return 0;
}
```

运行结果：
```
A use_count: 2
B use_count: 2
```

析构函数没有打印，对象泄漏。

一边改成 `std::weak_ptr`，不增加引用计数，即可打破循环。
```
class B {
public:
    std::weak_ptr<A> a;
    ~B() { std::cout << "Destructor B" << std::endl; }
};
```

weak_ptr 使用前需要 `lock()` 得到 shared_ptr，并判断对象是否还在。
```
if (auto pa = pb->a.lock()) {
    // A 仍存活
}
```
