## 说明

noexcept 作用于编译器的异常规范和代码生成阶段，声明函数不会抛出异常。

默认不加 noexcept 情况下，函数可以抛出异常，异常会沿调用栈向外传播，由外层 try/catch 处理。

手动添加 noexcept 后，等同于告诉编译器和调用方：“这个函数保证不抛异常。” 如果函数内部仍然抛出异常，程序会直接调用 `std::terminate` 终止，而不是继续向外抛。

在现代 C++ 开发中，析构函数、移动构造、移动赋值、swap 等“失败了也无法合理恢复”的操作，通常应声明为 noexcept。

## 不加 noexcept

示例代码：
```
#include <iostream>
#include <stdexcept>

class MyClass {
public:
    MyClass(int value) : a(value) {}

    void Show() {
        if (a < 0) {
            throw std::runtime_error("a < 0");
        }
        std::cout << "a:           " << a << std::endl;
    }

public:
    int a;
};

int main() {
    MyClass obj(-1);
    try {
        obj.Show();
    } catch (const std::exception& e) {
        std::cout << "catch:       " << e.what() << std::endl;
    }
    std::cout << "after catch" << std::endl;
    return 0;
}
```

运行结果：
```
catch:       a < 0
after catch
```

`Show` 没有声明 noexcept，异常可以抛出，被 `main` 中的 catch 捕获，程序继续执行。

## 添加 noexcept

示例代码：
```
#include <iostream>
#include <stdexcept>

class MyClass {
public:
    MyClass(int value) : a(value) {}

    void Show() noexcept {
        if (a < 0) {
            throw std::runtime_error("a < 0");
        }
        std::cout << "a:           " << a << std::endl;
    }

public:
    int a;
};

int main() {
    MyClass obj(-1);
    try {
        obj.Show();
    } catch (const std::exception& e) {
        std::cout << "catch:       " << e.what() << std::endl;
    }
    std::cout << "after catch" << std::endl;
    return 0;
}
```

运行结果：
```
terminate called after throwing an instance of 'std::runtime_error'
  what():  a < 0
```

`Show` 声明了 noexcept，内部仍然抛异常时，不会进入 catch，进程直接终止。

因此：noexcept 不是“禁止写 throw”，而是“承诺不抛；一旦违背就终止程序”。

## 移动操作中的 noexcept

容器扩容时，如果元素的移动构造是 noexcept，就可以放心把旧元素搬到新内存；如果移动可能抛异常，容器往往会改用拷贝，避免搬到一半失败、旧数据已被破坏。

示例代码：
```
#include <iostream>
#include <type_traits>
#include <vector>

class MyClass {
public:
    MyClass(int value) : a(value) {}
    MyClass(const MyClass& other) : a(other.a) {
        std::cout << "Copy constructor" << std::endl;
    }
    MyClass(MyClass&& other) : a(other.a) {
        std::cout << "Move constructor" << std::endl;
    }

public:
    int a;
};

int main() {
    std::cout << std::boolalpha;
    std::cout << "noexcept move: "
              << std::is_nothrow_move_constructible<MyClass>::value << std::endl;

    std::vector<MyClass> vec;
    vec.reserve(1);
    vec.emplace_back(1);
    vec.emplace_back(2);
    return 0;
}
```

运行结果（移动未声明 noexcept 时，扩容可能走拷贝）：
```
noexcept move: false
Copy constructor
```

给移动构造加上 noexcept 后：
```
    MyClass(MyClass&& other) noexcept : a(other.a) {
        std::cout << "Move constructor" << std::endl;
    }
```

运行结果：
```
noexcept move: true
Move constructor
```

注意：

`noexcept` 也可以写成 `noexcept(true)` 或 `noexcept(表达式)`；
`noexcept(func())` 作为运算符时，用来判断表达式是否保证不抛异常；
析构函数默认就是 noexcept，不要在析构函数里抛异常。
